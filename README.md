# Task 4 - Web Scraper GUI

This project is a Python-based GUI application that scrapes book data from books.toscrape.com.

## Features
- Web scraping using BeautifulSoup
- Dark mode GUI using Tkinter
- Search functionality
- Sorting by columns
- Live table display

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Tkinter

## How to Run
1. Install dependencies:
   pip install requests beautifulsoup4

2. Run:
   python task4.py
